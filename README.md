# pratix005.github.io

My portfolio. Plain HTML, CSS and JavaScript, no build step.

- `index.html`: content
- `style.css`: design tokens (light + dark), layout, motion
- `main.js`: theme toggle, clock, scroll reveals, cursor, and the redaction playground
  (a small JavaScript port of [aadhaarguard](https://github.com/Pratix005/aadhaarguard))

Run locally: open `index.html`, or `python -m http.server` in this folder.
